LEENA'S PERSONAL PORTFOLIO

FILES
- index.html: page content and structure
- style.css: colors, layout, responsive styling, animations
- script.js: mobile navigation and scroll reveal interactions

HOW TO OPEN
1. Keep all files in the same folder.
2. Double-click index.html to open it in your browser.

BEFORE SHARING ONLINE
1. In index.html, replace hello@example.com with your email address.
2. Update the About Me text if you want it to sound more personal.
3. Optional: add links to your GitHub, LinkedIn, or projects.

PUBLISHING
You can upload these files to a static hosting service such as GitHub Pages or Netlify.
No build step or JavaScript framework is required.
